# FitAi

# Inteligentný fitness tréningový systém s analýzou výkonu

## Cieľ / produkt
Webová aplikácia, ktorá:
- sleduje tréningy  
- analyzuje progres  
- odporúča zlepšenia  

---

## Hlavné funkcionality – jadro projektu
- Pridávanie tréningov (cviky, série, opakovania)  
- Ukladanie dát do databázy  
- Prehľad histórie tréningov  
- Jednoduchá analýza progresu (napr. nárast opakovaní)  

---

## Doplňujúce funkcionality
- Grafy výkonu (napr. progres v čase)  
- Odporúčanie tréningu pomocou AI  
- Rozdelenie tréningov (push/pull/legs alebo kalistenika)  
- Notifikácie (kedy máš trénovať)  
- Možnosť prihlásenia viacerých používateľov  
- Export dát (napr. do PDF)  
- Prepojenie s hodinkami / fitness trackermi  

---

## Technológie
- **Frontend:** HTML / CSS / JavaScript  
- **Backend:** Python (Flask)  
- **Databáza:** SQLite  
- **AI (voliteľné):** jednoduchý model alebo logika odporúčaní
